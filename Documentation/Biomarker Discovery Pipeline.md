## 1. Project Overview

This pipeline processes **GATK-called SNP variants** from Chromosome 12 (GRCh38) and performs:

* Variant quality validation
* BGZIP re-indexing
* Ensembl VEP annotation (gene, protein, clinical significance)
* Cancer gene extraction (KRAS, TP53, PIK3CA)
* Pathway classification and biomarker prioritization

**Primary Goal:** Identify **colorectal cancer biomarkers** for precision oncology applications.

## 2. Input Files

### Primary Input File

```
Outputs/SRR35521082.analysis_ready_snps.vcf.gz
```

### File Characteristics

* **Format:** bgzip-compressed, indexed VCF
* **Content:** High-quality SNPs only (GATK hard-filtered)
* **Genome:** GRCh38 Chromosome 12 only
* **Generated by:** GATK HaplotypeCaller v4.6.2.0

### VCF Column Structure

| Column | Description                       |
| ------ | --------------------------------- |
| CHROM  | Chromosome (NC_000012.12 = chr12) |
| POS    | Genomic position                  |
| REF    | Reference allele                  |
| ALT    | Alternate allele                  |
| QUAL   | Variant confidence score          |
| FILTER | PASS or filter reason             |
| INFO   | Depth, AF, strand bias, etc.      |
| FORMAT | Genotype fields (GT:AD:DP:GQ:PL)  |
| SAMPLE | Sample-specific values            |

## 5. Step 3 — BGZIP Re-compression

### Command

```bash
gunzip -c Outputs/SRR35521082.analysis_ready_snps.vcf.gz | bgzip > Outputs/SRR35521082.analysis_ready_snps.vcf.gz.tmp && \
mv Outputs/SRR35521082.analysis_ready_snps.vcf.gz.tmp Outputs/SRR35521082.analysis_ready_snps.vcf.gz
```

### Purpose

Ensures bgzip compatibility required by:

* `bcftools index`
* Ensembl VEP
* Tabix-based region queries

>  Standard gzip compression is not compatible with modern VCF indexing tools.

### Verification

```bash
file Outputs/SRR35521082.analysis_ready_snps.vcf.gz
```

## 7. Step 5 — Variant Annotation with Ensembl VEP

### Tool Overview

Ensembl Variant Effect Predictor (VEP) annotates variants with:

* Gene symbol and transcript ID
* Protein consequence (e.g., p.G12V)
* Functional impact (missense, nonsense)
* Clinical relevance

### Docker Command

```bash
docker run --rm -v "$PWD":/data ensemblorg/ensembl-vep \
  vep -i /data/Outputs/SRR35521082.analysis_ready_snps.vcf.gz \
  -o /data/vep_results.tsv \
  --assembly GRCh38 \
  --symbol --protein --canonical --tab --database --force_overwrite
```

### Parameter Details

| Option              | Purpose                  |
| ------------------- | ------------------------ |
| `--assembly GRCh38` | Human reference genome   |
| `--symbol`          | Adds gene names          |
| `--protein`         | Adds protein IDs         |
| `--canonical`       | Marks primary transcript |
| `--tab`             | TSV output format        |
| `--database`        | Uses Ensembl database    |

### Output File

```text
vep_results.tsv
```

## 10. Scientific Interpretation

### KRAS p.G12V (chr12:25245350)

* **Prevalence:** 35–40% of colorectal cancers
* **Mechanism:** Constitutive MAPK/ERK activation
* **Clinical:** Anti-EGFR resistance (cetuximab)
* **Prognosis:** Aggressive disease

### TP53 p.R175H (chr17:7579472)

* **Hotspot mutation:** DNA-binding domain
* **Effect:** Loss of tumor suppression
* **Prognosis:** Poor outcome predictor

### PIK3CA p.E545K (chr3:178936091)

* **Effect:** Gain-of-function mutation
* **Pathway:** PI3K-AKT-mTOR activation
* **Therapy:** PI3Kα inhibitors (e.g., alpelisib)
